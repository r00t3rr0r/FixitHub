COMMUNICATION PANEL BUTTONS FIX - SUMMARY
================================================================================

ISSUE:
------
The "📤 Feedback" and "➕ Action" buttons were not visible in the Communication 
Panel header on the Device Inspection page, even for authenticated admin users.

ROOT CAUSE:
-----------
The CommunicationPanel component was trying to access user data from useAuth(),
but the AuthContext only provides authentication status, not user profile data.

The user role information needed to be fetched separately from the 
GET /api/users/me endpoint.

SOLUTION:
---------
Modified CommunicationPanel.tsx to:
1. Remove dependency on useAuth() for user data
2. Add import of getUserProfile API and UserProfile type
3. Add state for user: const [user, setUser] = useState<UserProfile | null>(null)
4. Add useEffect hook to fetch user profile on component mount
5. User role check now works: user?.role === 'admin' || user?.role === 'staff'

FILES CHANGED:
--------------
1. /client/src/components/inspection/CommunicationPanel.tsx
   - Line 5-7: Removed useAuth import
   - Line 13: Added getUserProfile import
   - Line 71: Changed user state management
   - Lines 87-100: Added user profile fetching hook
