## Responsive Behavior

### Desktop (max-w-5xl)
- Card grid: 2 columns
- Full width specification display
- Optimal readability

### Tablet (md:)
- Card grid: Adaptive columns
- Readable font sizes
- Touch-friendly spacing

### Mobile
- Single column layout
- Stacked cards
- Full-width content
- Scrollable dialog

## Key Features

1. **Visual Hierarchy**: Clear section organization with color-coded indicators
2. **Intuitive Navigation**: Related information grouped together
3. **Accessibility**: Proper contrast ratios and semantic HTML
4. **Dark Mode**: Full support with appropriate color adjustments
5. **Responsive**: Works seamlessly on all screen sizes
6. **Performance**: Efficient rendering with conditional display
